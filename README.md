# Nano Challenge: Insights a partir do Spotify Dataset

Este repositório reúne o trabalho desenvolvido pela equipe do Time 6 para o nano challenge da Residência em IA do Instituto ELDORADO, em parceria com a UnB e o Lab Livre.

## Desafio

Como transformar dados musicais em evidências para apoiar decisões de negócio, marketing e experiência do usuário?

## Objetivo

A equipe busca analisar o dataset do Spotify para identificar padrões, tendências e relações entre atributos musicais e popularidade, transformando dados em insights relevantes. O trabalho contempla introdução a dados, coleta, integração, limpeza, engenharia de atributos, análise exploratória, estatística, visualização, hipóteses, métricas, avaliação crítica e uso responsável de IA.

## Entregáveis

- Notebook em formato .ipynb com análise exploratória, limpeza, visualizações e hipóteses testadas.
- Apresentação com gráficos, principais descobertas e conclusões do estudo.

## Estrutura do repositório

- `dataset/`: arquivos do dataset original e limpo.
- `notebooks/`: notebook da análise.
- `apps/`: scripts auxiliares.
- `docs/`: materiais e documentação do projeto para o Git Pages (https://gabrielmacielbr.github.io/r.ia-spotify_nano_challenge/).
